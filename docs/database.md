# Варианты базы данных

Enigma по умолчанию использует SQLite, потому что он сразу работает локально и хорошо подходит для демо, прототипов и разработки на одной машине.

Для настоящего хостинга open-source мессенджера лучше выбрать PostgreSQL:

- безопаснее обрабатывает конкурентные записи
- проще настраивать резервные копии
- удобнее поддерживать миграции и наблюдаемость
- Supabase, Neon, Railway и Render дают быстрый managed PostgreSQL

## Рекомендуемый путь к продакшену

1. Перенести схему из `database/schema.sql` в миграции.
2. Заменить SQLite DSN в `config/database.php` на `pgsql:` DSN из переменных окружения.
3. Заменить SQLite-доступ в `server/ws-server.js` на пакет `pg`.
4. Добавить общий auth-токен или полноценную проверку сессии для WebSocket-сервера, чтобы не доверять ID пользователя из браузера.

SQLite намеренно оставлен в стартере, чтобы проект можно было клонировать и запустить без облачных аккаунтов.
