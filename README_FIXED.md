# Enigma fixed build

Запуск:

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:8080`.

Демо-аккаунт: `demo / enigma123`.

Что исправлено:
- backend больше не требует `pdo_sqlite` или `sqlite3` CLI, данные хранятся в `database/store.json`;
- отправка сообщений работает через WebSocket, а при недоступном сокете — через HTTP API;
- сообщения сохраняются и доступны после перезагрузки;
- кнопка отправки стала маленькой круглой кнопкой снизу поля ввода;
- исправлена ошибка звонка `peer.id`/`peer.user_id`;
- убран мусор macOS `._*` и `node_modules` из сборки.
